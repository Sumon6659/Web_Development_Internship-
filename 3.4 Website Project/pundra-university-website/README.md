## 📌 ১. প্রজেক্টের সংক্ষিপ্ত বিবরণ (Project Overview)

এই প্রজেক্টটি বগুড়ার ঐতিহাসিক পুন্ড্রবর্ধন অঞ্চলে অবস্থিত **পুন্ড্র ইউনিভার্সিটি অব সায়েন্স অ্যান্ড টেকনোলজি (Pundra University of Science & Technology - PUB)**-এর অফিসিয়াল ওয়েবসাইটের আদলে তৈরি একটি আধুনিক, রেসপনসিভ ও নান্দনিক এডুকেশনাল ওয়েবসাইট।

- **অফিসিয়াল রেফারেন্স ওয়েবসাইট:** `https://pundrauniversity.ac.bd/`
- **টেকনোলজি স্ট্যাক:** **HTML5 + CSS3 (Pure Vanilla) + JavaScript (ES6+ Vanilla)**
- **অফলাইন সাপোর্ট:** কোনো এক্সটার্নাল সিডিএন বা ফন্ট লিঙ্ক ফেইল করলেও ওয়েবসাইটটির সকল লেআউট ও আইকন (Inline SVG) সম্পূর্ণ অফলাইনে ত্রুটিহীনভাবে কাজ করে।
- **বাস্তব ডেটা ও পরিসংখ্যান:** ১২টি একাডেমিক বিভাগ, ২২টি স্নাতক ও স্নাতকোত্তর প্রোগ্রাম, অফিসিয়াল টিউশন ফি ও ওয়েভার কাঠামো, বিভাগীয় প্রধানদের তথ্য ও নোটিশ বোর্ড সম্পূর্ণ বাস্তব তথ্যের ভিত্তিতে সাজানো।

## 🚀 ২. কীভাবে ওয়েবসাইটটি চালাবেন (How to Run Locally)

এই প্রজেক্টটি চালাতে কোনো `npm install`, Node.js বা বিল্ড টুলের প্রয়োজন নেই। এটি সম্পূর্ণ স্ট্যাটিক সাইট।

### পদ্ধতি ১: ভিএস কোড লাইভ সার্ভার (VS Code Live Server - সর্বাপেক্ষা সহজ)
1. **VS Code**-এ `pundra-university-website` ফোল্ডারটি ওপেন করুন।
2. ভিএস কোডের এক্সটেনশন মার্কেটপ্লেস থেকে **Live Server** ইনস্টল করা না থাকলে ইনস্টল করুন।
3. `index.html` ফাইলে রাইট-ক্লিক (Right Click) করে **"Open with Live Server"** অপশনে চাপুন।
4. স্বয়ংক্রিয়ভাবে আপনার ডিফল্ট ব্রাউজারে `http://127.0.0.1:5500/index.html` চালু হয়ে যাবে।

### পদ্ধতি ২: সরাসরি ব্রাউজারে ওপেন (Direct Browser Double Click)
- ফাইল ম্যানেজারে গিয়ে `pundra-university-website/index.html` ফাইলে ডাবল-ক্লিক করলেই যেকোনো আধুনিক ব্রাউজারে (Google Chrome, Microsoft Edge, Mozilla Firefox) ওয়েবসাইটটি সম্পূর্ণ কার্যকরভাবে ওপেন হবে।

### পদ্ধতি ৩: পাইথন লোকাল সার্ভার (Python Local Server)
পাওয়ারশেল বা টার্মিনালে প্রজেক্ট ডিরেক্টরিতে গিয়ে নিচের কমান্ডটি রান করুন:
```bash
python -m http.server 8000
```
এরপর ব্রাউজারে যান: `http://localhost:8000`

## 💡 ৫. শিক্ষানবিসদের জন্য শিখন গাইড (Beginner's Learning Guide)

আপনি যদি ওয়েব ডেভেলপমেন্টের প্রাথমিক শিক্ষার্থী হয়ে থাকেন, তবে এই প্রজেক্টের কোড থেকে আপনি যা যা শিখতে পারবেন:

1. **HTML5 সিম্যান্টিক ট্যাগ:** `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<footer>` ট্যাগের সঠিক ব্যবহার।
2. **আধুনিক সিএসএস ফ্লেক্সবক্স ও গ্রিড:** কোনো বুটস্ট্র্যাপ ছাড়া কীভাবে আধুনিক রেসপনসিভ কার্ড গ্রিড (`grid-template-columns: repeat(auto-fit, minmax(280px, 1fr))`) তৈরি করতে হয়।
3. **কাস্টম সিএসএস ড্রপডাউন ও অফক্যানভাস ড্রয়ার:** মোবাইল ডিভাইসে সহজে আঙুল দিয়ে স্ক্রল ও মেনু খোলার জন্য সিএসএস ট্রানজিশন ও ট্র্যান্সফর্মের ব্যবহার।
4. **ভ্যানিলা জাভাস্ক্রিপ্ট ডম ম্যানিপুলেশন (DOM Manipulation):** 
   - `document.querySelector()` এবং `addEventListener()` দিয়ে ক্লিক ইভেন্ট হ্যান্ডলিং।
   - ফর্ম ভ্যালিডেশন (নাম, ফোন নম্বর ১১ ডিজিট কিনা যাচাই, জিপিএ স্কেল চেক)।
   - গণিত ভিত্তিক লজিক: এসএসসি ও এইচএসসি জিপিএ অনুযায়ী টিউশন ফি থেকে কত টাকা ছাড় (Discount) পাওয়া যাবে তা ক্যালকুলেট করা।
5. **ইউআরএল প্যারামিটার রিডিং (URLSearchParams):** সার্ভার ছাড়া কেবল ব্রাউজারের জাভাস্ক্রিপ্ট দিয়ে `window.location.search` থেকে `?id=cse` পড়ে সেই অনুযায়ী পেজের কনটেন্ট পরিবর্তন করা।
